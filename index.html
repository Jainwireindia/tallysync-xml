Item master

Your shorthand code on the left, the exact TallyPrime stock item name on the right. The Tally name must match your stock item letter for letter or the import will reject that line. Height and length are in feet and drive the sheet, roll, chainlink and sq.ft formulas. Add comma-separated variants for any other codes or spellings a rate sheet might use for the same item.

Add an item

Code, Tally stock item name and category are all required. The Tally name must match your stock item letter for letter or the import will reject that line. Height and length are filled in from the code where it can be read — check them.

One item per line, tab or comma separated: code, tally name, category, unit, height, length, bundle kg, HSN, GST%, variants. Only code and Tally name are required. Variants are other codes/spellings for the same item — separate multiple with a comma inside that last field.

Party master

Only the parties you actually bill need to be here. The name must match the TallyPrime ledger exactly. State decides the tax split — anything outside Kerala gets IGST instead of CGST and SGST. Add an alias if your rate sheet writes the name differently to Tally. Address, pincode and place are optional but recommended — without them Tally leaves the printed invoice's buyer address blank until someone reselects the party by hand.

Excel with a Name column and a GSTIN column (any order, any extra columns are ignored). State is worked out automatically from each GSTIN's state code — no state column needed. Add Address, Pincode and/or Place columns to pull those in too. Existing parties are matched by name and updated; anything new is added.

Add a party

The Tally ledger name is required — it must match the ledger in TallyPrime letter for letter. Everything else is optional, but address, pincode and place are what stop Tally leaving the buyer address blank on the printed invoice.

One party per line, tab or comma separated: ledger name, GSTIN, state, alias, address, pincode, place. Export from Tally with Display > List of Accounts > Ledgers, or paste straight from a spreadsheet. Address, pincode and place are optional — they let bills print with the buyer's address without reselecting the party in Tally.

Pricing rules

Rates on your sheet are always tax-inclusive, so every formula divides the tax back out and rounds up. Length is the fallback used when an item has no length of its own.

Bundle weights

For bundle items, the quantity on your sheet is a count of bundles. Billed weight is that count times the weight below.

Backup & restore

Everything this tool knows — items, parties, pricing rules, Tally settings, and the export log — in one file. Download it before switching computers or browsers, sharing this tool with a teammate, or moving from a downloaded copy into a Claude chat. Restoring replaces whatever is currently loaded, so grab a fresh backup first if you're not sure.
